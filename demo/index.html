Reveal on scroll.

Elements animate in as they reach the screen. 3.6 kB, typed, no dependencies, and it respects reduced motion.

npm install reveal-on-scroll

Options

Set any option on one element, or for the whole page in ROS.init().

anchor-placementcenter-center
